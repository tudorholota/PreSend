Privacy Policy — PreSend

Last updated: August 29, 2026

PreSend is a browser extension that analyzes Romanian text submitted by users and classifies it for potentially offensive language.

Information We Process

PreSend processes only the text that a user explicitly enters into the extension and submits for analysis.

The submitted text is transmitted securely to the PreSend backend API over HTTPS in order to generate a classification result.

PreSend does not automatically read browsing history, passwords, cookies, or unrelated content from websites visited by the user.

How We Use Information

Submitted text is used solely to generate the requested classification, such as Normal, Profanity, Insult, or Abuse, together with confidence scores.

Submitted text is not used for advertising, marketing, user profiling, or sale to third parties.

Message Storage

PreSend does not intentionally store submitted message content in a persistent application database.

The text is processed by the machine learning model and is not intentionally retained by the PreSend application after the request has been processed.

Server and Technical Data

The PreSend backend is hosted using third-party cloud infrastructure provided by Render.

As part of normal server operation, the hosting provider may process standard technical information such as IP addresses, timestamps, request status information, and other server metadata.

Sharing of Information

PreSend does not sell user data.

Data submitted for analysis may be processed by infrastructure providers necessary to operate the service, including Render.

Security

Communication between the PreSend browser extension and the backend uses HTTPS encryption.

Browser Permissions

PreSend requests access only to the PreSend backend API domain. This permission is required so the extension can send user-submitted text to the analysis service and receive the classification result.

Changes to This Privacy Policy

This Privacy Policy may be updated if PreSend's functionality or data-handling practices change.
